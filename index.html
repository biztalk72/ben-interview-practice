나에게 맞는 음성

영어는 Kokoro 신경망 엔진, 한국어는 기기 음성으로 읽습니다. 영어 엔진과 음성을 바꿔 비교해보세요.

Kokoro는 기기에서 실행되는 별도 영어 음성 엔진입니다. 첫 사용 시 약 100MB 모델을 다운로드하며, 기기 성능에 따라 생성 시간이 필요합니다. 한국어는 기기 음성을 사용합니다.

모바일에서는 재생 버튼을 직접 눌러 시작하세요. 화면 잠금·앱 전환 시 재생이 중단될 수 있습니다. 오프라인 음성은 기기에 설치된 음성에 따라 다릅니다.

연습을 이어가는 방법

1. 읽고, 가리고, 말하기

질문마다 한·영 모범 답안이 먼저 표시됩니다. ‘답안 수정’으로 한국어·영어를 직접 다듬을 수 있습니다. 답변을 읽은 뒤 ‘답변 가리기’를 누르세요. 타이머를 시작하고 소리 내어 답한 다음, 연습 완료를 표시합니다.

2. 한·영 어느 쪽을 수정해도 상호 갱신

‘자동번역 켜기’를 한 번 누르면 기기 내 번역 모델을 준비합니다. 번역 방향에 따라 첫 사용 시 수백 MB 모델 다운로드가 필요할 수 있습니다. 이후 한국어 또는 영어 입력을 멈추면 반대쪽 답안을 자동 갱신합니다. 마지막으로 직접 수정한 언어가 기준이며 자동 결과는 다시 역번역하지 않습니다. 자동번역은 문체를 다듬는 전문 윤문이 아닌 기계번역이므로 확인하고 직접 고칠 수 있습니다. 이전 답안 복원과 모범 답안 초기화도 가능합니다.

3. 듣고 따라 말하기

영문 답변·한국어 답변·질문·큐카드·한영 답안 읽기를 선택할 수 있습니다. 음성과 속도, 반복 설정은 톱니바퀴에서 바꿉니다. 원문에 영문 답변이 없으면 안내가 표시됩니다.

4. 홈 화면에서 열기

iPhone Safari: 공유 → 홈 화면에 추가. Android Chrome: 메뉴 → 홈 화면에 추가 또는 앱 설치. 최초 접속 후 자료를 캐시하며 오프라인 읽기를 지원합니다.

5. 기록은 기기별로 보관

즐겨찾기·완료 표시·메모·수정한 한영 답안은 브라우저에 저장됩니다. 기기 간 자동 동기화는 없습니다. 아래 백업 파일을 다른 기기로 가져오면 이어서 연습할 수 있습니다. 브라우저 데이터 삭제 시 기록이 사라질 수 있습니다.
